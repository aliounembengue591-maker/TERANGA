## 💎 Identité & Présentation

**TERANGA BEAUTY** est la première marketplace de mode et beauté sénégalaise haut de gamme, dédiée aux maisons d'exception, créatrices et artisans de Dakar.

- **URL de Production :** `https://teranga-beauty-luxe.web.app`
- **Ancien domaine (redirection 301 automatique) :** Redirigé vers `https://teranga-beauty-luxe.web.app`
- **Paiements Directs :** Wave & Orange Money 100% direct aux créatrices
- **Identité Visuelle :** Monogramme impérial **T** or sur fond bordeaux prestige (`#681427`)

## 🚀 Commandes de Déploiement Firebase

Pour créer et déployer sur le site de production luxe :

```bash
# 1. Création du site d'hébergement dédié (si non existant)
firebase hosting:sites:create teranga-beauty-luxe --project gen-lang-client-0777029768

# 2. Build de l'application
npm run build

# 3. Déploiement exclusif sur le site luxe
firebase deploy --only hosting:teranga-beauty-luxe
```
